# 申论答题纸

申论页面位于主导航的“申论”入口。答题区按照每行 25 格的申论答题纸布局显示，右侧同时提供标准答案、普通备注和批注卡片。页面会自动保存本地草稿；点击“保存回顾”后，内容会进入卡片库的“申论复盘”页签。

## 答题区

- 可切换 200、400、800、1000 字模板，页面会自动生成对应行数。
- 汉字各占一格；连续中文标点每两个共用一格。闭合标点落在行尾时会与前一文字共格，把第 25 格留给后续正文；英文或数字连续两个字符占一格，并在格内左右横向排列。
- 正文默认逐格连续排满每行 25 格，不会因中文分词在行尾留下多余空列；开、闭标点的规范换行规则仍然保留。
- 普通空格占一格并计入总字数；Tab 产生的结构缩进空位不计字数。
- 点击任意方格可移动写作位置；点击正文后的空白格会补齐不可见结构空位，再从目标方格继续输入或粘贴。
- 支持与普通文本框一致的中文输入法组合输入，未上屏的拼音会显示在当前方格并随页面滚动；直接使用系统粘贴快捷键也可从当前光标灌入文本并自动换行，中文标点不会单独出现在行首。
- 编辑时仅在当前方格显示一处可见光标；承载中文输入法的输入层不会重复绘制第二个光标。
- 模板最后一格可以正常输入中文；继续输入会自动生成淡红色溢出格，不会吞掉末格文字。
- 浏览器放大或窄屏时，工具栏保持在可见区域，答题纸改为独立双向滚动；右侧功能区会完整下移，不会被页面横向裁切。
- 每累计 200 字会在对应行左侧显示灰色位置标记。超出模板的格子会以淡红色提示。
- 选择文字后可使用加粗、文字颜色、连续下划线和连续删除线；装饰线会横贯整个选区，而不是只画在单个字形下方。折叠光标时选定的格式会应用到后续输入，正文与格式修改均支持撤销、重做、复制和剪切。

## 保存与回看

- 标题默认取正文前 24 个可见字符，也可直接编辑；本地草稿会记录标题是否经过手动修改。
- 点击“新建申论”会打开独立空白答题纸，并清除当前活动草稿中的旧记录编号；随后首次保存会创建新复盘，不会覆盖或删除卡片库中的上一份申论。
- 首次点击“保存回顾”会创建申论复盘；从卡片库进入编辑后再次保存，只更新原记录，不创建历史版本。
- 如果本地草稿指向的原复盘已不存在，保存时会自动创建新记录并进入新的编辑地址；卡片库加载失败时可直接点击“重新加载”。
- 卡片库的“申论复盘”页签展示标题、摘要、模板、实际字数和更新时间，支持按标题、正文摘要或字数模板本地模糊搜索；搜索词之间可用空格组合，清空搜索即可恢复全部卡片。申论卡片使用较低透明度的中性玻璃底，背景透视更弱。
- 当前申论支持预览、置顶/取消置顶、编辑和归档；置顶稿优先排列。切换到“已归档”可继续预览并恢复归档，归档稿不提供编辑入口。预览保留正文的加粗、颜色、下划线和删除线格式，也可查看标准答案、备注与批注。
- 服务端使用独立的 `shenlun_reviews` 数据表保存申论内容和卡片状态，迁移版本为 9。

## 备注与批注

右侧标准答案支持直接输入、粘贴，或导入 `.txt`、`.md` 文件。普通备注支持文本和内部复盘链接标记：

```text
[查看复盘](/review#review-item-条目编号)
```

预览中的链接可以跳转到复盘页面对应条目。标准答案、备注与批注使用不同透明度的中性玻璃分区，批注保留冷灰蓝边界提示，三类内容互不影响。

在答题区选中文字后，“添加批注”会悬浮在选区末格旁边并随滚动、缩放保持就近显示；填写内容后，右侧会生成透明批注卡片，同时显示浅色箭头连接原文和批注。批注可以单独编辑、删除和上下调整顺序；原文变化后会保留批注并提示原文位置已变化，失联批注不会阻止当前申论稿继续保存。

## 快捷键

- `Alt+1`、`Alt+2`、`Alt+3`、`Alt+4`：切换字数模板。
- `Ctrl/Cmd+V`：从当前方格粘贴正文。
- `Ctrl/Cmd+A` 后按 `Delete` 或 `Backspace`：清空正文。
- `Ctrl/Cmd+B`、`Ctrl/Cmd+U`、`Ctrl/Cmd+Shift+X`：加粗、下划线、删除线。
- `Ctrl/Cmd+Z`、`Ctrl/Cmd+Y`：撤销、重做。
- `Ctrl/Cmd+S`：保存回顾或更新当前复盘记录。
- `Ctrl/Cmd+Enter`：选中文字后打开新批注。
- `Ctrl/Cmd+P`：打开浏览器打印面板，可选择导出 PDF。
- `Esc`：取消当前选区或批注编辑。

打印样式会隐藏编辑控件，保留申论标题、答题格、标准答案、备注预览、批注卡片和可点击复盘链接。
