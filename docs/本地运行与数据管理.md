# 本地运行与数据管理

## 环境要求

- Node.js 版本不低于 22.12。
- 使用 npm 安装和运行项目依赖。

## 安装与开发启动

首次运行时执行：

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

开发服务仅监听本机。启动后，前端地址为 `http://127.0.0.1:5173`，后端健康检查地址为 `http://127.0.0.1:8787/api/health`。

`package-lock.json` 必须随依赖变更提交，并保留 `@types/better-sqlite3` 开发依赖，以支持服务端 TypeScript 导入 SQLite 驱动。安装完成后执行 `npm run typecheck` 验证类型依赖可用。

## 构建与运行

执行以下命令生成前后端构建产物并启动构建服务：

```powershell
npm run build
npm start
```

前端构建产物位于 `dist/client`，服务端构建产物位于 `dist-server`。

## 配置与数据

本地配置从 `.env` 读取，默认数据目录为项目下的 `./data`，运行时会解析为绝对路径。DeepSeek 模型固定为 `deepseek-v4-flash`。`.env` 只供本机使用，可能包含 DeepSeek 密钥，禁止提交到版本库；提交配置示例时只能保留空密钥。
