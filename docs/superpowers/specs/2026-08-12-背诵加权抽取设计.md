# 背诵加权抽取设计

## 目标

背诵随机抽取同时考虑不会次数、熟练次数和距上次抽取时间。新卡与长期未抽取卡优先，近期抽过或多次熟练的卡片逐步降权，但任何卡片的总权重不得低于 `0.25`。

## 权重公式

```text
基础权重 = (1 + 不会次数) / (1 + 熟练次数)

时间系数：
从未抽取 = 2.0
已抽取 = clamp(0.5 + 距上次抽取天数 / 14, 0.5, 2.0)

卡片权重 = max(0.25, 基础权重 × 时间系数)
题面权重 = 卡片权重 / 该卡片题面数量
```

- 不会次数读取 `cards.wrong_count`。
- 熟练次数按卡片汇总 `review_logs.rating = 'good'` 的历史记录。
- 新卡的不会次数、熟练次数均为 0，且从未抽取，因此卡片总权重为 `2.0`。
- 时间系数从刚抽取时的 `0.5` 线性恢复，21 天达到封顶值 `2.0`。
- 同一张卡片的多个题面均分卡片总权重，避免题面数量放大整张卡片的抽取概率。

## 数据与行为

新增可空字段 `cards.last_drawn_at`。历史卡片默认空值，按从未抽取处理。背诵会话成功选出题面后，以同一时间批量更新被选中卡片的 `last_drawn_at`；同一卡片在同一轮只更新一次。

固定顺序保持现有顺序，随机顺序使用新的无放回加权抽取。现有归档、AI 状态、板块、标签、日期和指定卡片筛选保持不变。

## 验证

- 新卡卡片总权重为 `2.0`。
- 不会次数提高权重，熟练次数降低权重。
- 最终卡片权重下限锁定为 `0.25`。
- 从未抽取和 21 天未抽取的时间系数为 `2.0`，刚抽取为 `0.5`。
- 多题面卡片只均分总权重；随机抽样无重复。
- 创建会话后写回本次时间，未选中卡片不更新。
