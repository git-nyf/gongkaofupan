# 申论复盘与类 Word 编辑设计

## 目标

在现有申论答题纸上补齐可持续复盘能力和接近 Word 的基础编辑体验。用户能够在任意方格定位光标，使用键盘完成输入、粘贴、选择、删除、撤销和文字格式设置；保存后在卡片库的“申论复盘”标签中预览，并可返回原记录继续编辑。

## 已确认决策

- 工具栏采用紧凑式横向功能区，保留模板、加粗、下划线、删除线、撤销、重做、保存回顾和导出 PDF。
- 移除“粘贴文本”“清空答题”“清空备注”等专属按钮，编辑操作统一使用键盘和选区。
- 保存采用独立申论复盘数据表，不复用卡片表；再次编辑保存时覆盖更新原记录，不生成历史版本。
- 标题默认取正文前 24 个可见字符，允许用户修改。
- 标准答案支持直接输入、系统粘贴，以及导入 `.txt`、`.md` 文件，并随复盘记录持久化。
- 本地草稿继续自动保存；只有点击“保存回顾”才新建或更新数据库记录。
- 卡片库增加与“AI 优化稿”“用户初始稿”同级的“申论复盘”标签。

## 编辑模型

正文以纯文本和格式区间共同组成：

```ts
interface ShenlunMark {
  id: string;
  type: 'bold' | 'underline' | 'strike';
  start: number;
  end: number;
}
```

方格仍由现有申论排版器生成，确保中文和中文标点一字符一格、英文和数字两字符一格、每行 25 格、标点避首、200 字提示和超限警示不变。编辑层维护文本选区 `{ start, end }`，方格点击、拖选和键盘输入都转换为文本索引。

点击正文末尾之后的空白方格时，编辑器用内部结构空位补齐到目标格，再插入输入内容；结构空位在答题纸上显示为空格，不计入标题和正文预览。这样既允许从任意格开始书写，也不改变普通文本的字数统计。

输入和粘贴采用插入语义：替换当前选区，并将后续正文向后顺延。删除、退格、Ctrl+A、Ctrl+Z、Ctrl+Y、Ctrl+B、Ctrl+U 和 Ctrl+Shift+X 均作用于当前答题区；当焦点位于备注、批注或标准答案输入框时，保留系统原生编辑行为。

格式区间随正文插入、删除和选区替换同步平移或裁剪。没有选区时点击格式按钮会切换后续输入格式；有选区时则对选中文字切换对应格式。

## 右侧工作区

右侧保持约三分之一宽度，使用项目已有的透明玻璃材质并分成三个连续区域：

1. 标准答案：输入区、文本文件导入和对照内容。
2. 普通备注：保留简易超链接语法与可点击预览。
3. 批注：保留选中文字后的箭头指向，增加上移、下移按钮。

备注和批注继续用不同颜色区分。批注顺序变化后重新测量连接器起止点，箭头自动跟随新位置。降低透明度偏好启用时，右侧面板退化为高不透明度实色背景，避免阅读困难。

## 数据与接口

新增 `shenlun_reviews` 表，字段包括：

- `id`、`title`、`template`、`text`；
- `marks_json`、`notes`、`standard_answer`、`annotations_json`；
- `created_at`、`updated_at`。

新增接口：

- `GET /api/shenlun-reviews`：按更新时间倒序返回复盘摘要；
- `GET /api/shenlun-reviews/:id`：读取完整复盘；
- `POST /api/shenlun-reviews`：新建复盘；
- `PUT /api/shenlun-reviews/:id`：更新原复盘。

接口校验模板值、标题长度、格式区间和批注结构。服务端生成记录编号和时间，列表摘要去除内部结构空位后截取正文。

## 卡片库复盘视图

卡片库第三个标签显示申论复盘卡片，包含标题、摘要、字数模板、实际字数和更新时间。点击“预览”打开只读详情，显示带格式的正文、标准答案、备注和批注；点击“编辑”进入 `/shenlun/:reviewId`。

编辑页加载成功后以数据库记录覆盖本地空白草稿，并记住当前记录编号。保存成功后继续停留在当前页，后续保存更新同一条记录；新建页面 `/shenlun` 不携带记录编号。

## 状态与失败反馈

- 读取复盘失败时保留本地草稿，不覆盖用户当前输入。
- 保存按钮显示保存中、已保存或失败，失败时正文与本地草稿不丢失。
- 文件导入只接受 `.txt`、`.md`，读取失败在标准答案区域内提示。
- 预览列表空状态直接提供“新建申论”入口。

## 验证标准

- 服务端测试覆盖迁移、新建、列表、详情、更新原记录、校验失败和不存在记录。
- 编辑核心测试覆盖任意格定位、输入/粘贴替换、全选删除、撤销重做和格式区间变换。
- 页面测试覆盖工具栏快捷键、移除旧按钮、标准答案导入、批注排序、保存新记录和更新原记录。
- 卡片库测试覆盖第三标签、预览和编辑跳转。
- 通过类型检查、生产构建，并在桌面和窄屏 Chromium 中检查方格、玻璃侧栏、弹层和文字不重叠。
