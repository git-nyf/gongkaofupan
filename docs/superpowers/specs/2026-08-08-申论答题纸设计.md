# 申论答题纸设计

## 1. 业务目标

在现有公考记忆卡应用中新增独立“申论”页面，为用户提供接近真实申论答题纸的文本排版、字数核对、复盘关联、批注和打印导出能力。

本功能需要同时满足以下结果：

- 固定每行 25 格，按 200、400、800、1000 字模板生成对应答题区。
- 中文和中文标点每字符占一格，连续拉丁字母或阿拉伯数字每两个字符共占一格。
- 粘贴文本后自动分词、避开行首标点、实时计算占格字数并显示每 200 字水印。
- 右侧同时承载普通备注和选中文字批注，并以不同颜色区分。
- 批注通过浅色箭头连接到答题纸中的原文位置。
- 普通备注中的内部链接可以跳转到复盘条目，打印为 PDF 后仍可点击。
- 支持已确认的键盘快捷键，并保留备注输入框中的系统编辑快捷键。

## 2. 范围边界

### 2.1 本轮范围

- 新增 `/shenlun` 页面及侧栏入口。
- 新增纯前端申论排版、批注、备注、本地草稿保存和打印导出能力。
- 为复盘条目增加稳定锚点，并处理从申论备注跳转后的定位。
- 增加与新页面直接相关的单元测试、组件测试和打印样式验证。

### 2.2 不在本轮范围

- 不新增服务端表、数据库迁移或跨设备同步。
- 不增加富文本编辑器、云端协作、手写识别或自动评分。
- 不解析任意 Markdown，只支持已确认的内部链接语法。
- 不给清空答题或清空备注设置快捷键，避免误触。
- 不改造现有复盘业务结构，只补充稳定锚点与跳转定位。

## 3. 信息架构与视觉方向

### 3.1 导航

侧栏新增“申论”入口，路径为 `/shenlun`，顺序紧跟“复盘”，位于“图谱”之前。入口使用与现有导航一致的 Lucide 线性图标、即时按压反馈和激活标记。

### 3.2 页面布局

页面沿用现有石墨黑侧栏、朱红强调色和半透明材质体系，并参考 Apple 桌面应用的克制层级、即时反馈、空间一致性和减少动态效果支持。

主页面从上到下分为三部分：

1. 页头：标题“申论”和实时字数状态。
2. 工具栏：字数模板、粘贴、清空答题、清空备注和导出 PDF。
3. 工作区：左侧答题纸约占三分之二，右侧批注与备注栏约占三分之一。

工作区不是营销式卡片集合。答题纸保持纸张感和清晰网格；右侧栏是一个连续的独立滚动区域，普通备注和批注同时出现，不使用标签页。

### 3.3 颜色区分

- 答题纸：中性白底，细浅朱红网格线。
- 普通备注：浅灰绿色背景和较深的中性文字。
- 批注：浅冷蓝背景、蓝色细边和浅蓝连接箭头。
- 超限文字：淡红底色，但保持文字可读。
- 字数水印：中性灰，不占用方格。

界面不使用装饰性渐变、光球、彩色光晕、紫色主调或夸张圆角。批注和备注表面圆角不超过 8 像素。

## 4. 答题纸排版

### 4.1 模板

页面提供以下固定模板：

| 模板 | 基础行数 | 基础格数 |
| --- | ---: | ---: |
| 200 字 | 8 行 | 200 格 |
| 400 字 | 16 行 | 400 格 |
| 800 字 | 32 行 | 800 格 |
| 1000 字 | 40 行 | 1000 格 |

每行始终为 25 个正方形方格。切换模板后立即按模板重建基础行数，不改变已粘贴原文、普通备注或批注。

若当前内容超过模板容量，基础答题纸后追加仅用于显示超限内容的警示行。警示行继续保持 25 格，但已占用的超限格使用淡红底色；工具栏同时显示超出数量。这样既保留模板的正式行数，也不会隐藏或截断用户文本。

### 4.2 字符占格

- 汉字、中文标点、全角字符和其他非拉丁字符各占一格。
- 连续拉丁字母或阿拉伯数字按原顺序分组，每两个字符共占一格；奇数长度的最后一个字符单独占一格。
- 半角标点不参与两字符合格，按一个字符占一格处理。
- 粘贴文本中的回车会结束当前行并从下一行开始，但回车本身不计字数。
- 仅用于排版的空格不计字数，也不占方格。
- 实时“总字数”指实际占用方格数，而不是原始字符串长度。

每个合格单元仍保留内部字符级元素，因此用户可以准确选择一个拉丁字符，而不是只能选择整格。

### 4.3 分词与标点

排版优先使用浏览器 `Intl.Segmenter` 的中文词语分段能力。每个词语作为不可拆分单元尝试放入当前行；当前行剩余格数不足时，整词移到下一行。单个单元超过 25 格时才允许按格拆分。

中文闭合标点、逗号、句号、顿号、分号、冒号、问号和感叹号不能单独出现在行首。当标点将落入新行首格时，将前一字符连同标点一起移到下一行；上一行允许留下空格。成对开标点不单独停留在行末。

若运行环境不支持 `Intl.Segmenter`，使用确定性的字符级回退规则，仍保证占格、换行和标点避首，不额外引入分词依赖。

### 4.4 字数标记

每累计 200 个有效占格，在对应行末高度的答题纸左侧留白中显示灰色水印：`(200字)`、`(400字)`、`(600字)`、`(800字)`、`(1000字)`。

水印绝不进入 25 列网格，不占方格，不覆盖文字。只渲染当前已经达到的累计字数位置；空白模板不提前显示未达到的标记。

## 5. 粘贴与状态

点击“粘贴文本”时调用剪贴板文本读取能力。读取成功后用新文本替换当前答题内容并立即重新排版；读取失败时保留原内容，并在工具栏附近显示稳定错误提示。

当页面本身获得焦点且备注输入框没有聚焦时，`Ctrl/Cmd+Shift+V` 执行相同的粘贴流程。备注输入框聚焦时不拦截系统粘贴、撤销、重做和选择快捷键。

答题内容、模板、普通备注和批注使用带版本号的本地草稿结构自动保存。解析失败或版本不兼容时回退到空白草稿，不影响应用其他页面数据。

## 6. 普通备注与复盘链接

### 6.1 备注输入与显示

右侧栏顶部保留普通文本输入区，下方显示解析后的备注内容。普通文本保持原顺序和换行，只有以下语法被解析为链接：

```text
[显示文字](/review#review-item-条目ID)
```

解析过程使用 React 元素生成，不使用不受控的 HTML 注入。只允许 `/review#review-item-` 开头的内部目标；不符合规则的内容按普通文本显示。

链接渲染为带链条图标的可点击标签。点击后进入复盘页，展开目标所在板块和小节，选中对应条目并滚动到稳定锚点。

### 6.2 复盘锚点

每条可跳转的复盘条目获得稳定 DOM 标识：

```text
review-item-<条目ID>
```

复盘页在数据完成加载后读取地址哈希。若目标当前位于折叠板块、未选小节或非当前条目，页面先恢复对应可见状态，再执行滚动与短暂高亮。目标不存在时保持复盘页正常可用，不展示错误页面。

## 7. 选中文字批注

### 7.1 创建流程

用户在答题纸中拖动选择文字后，选区附近出现紧凑的“添加批注”操作。点击该操作或按 `Ctrl/Cmd+Enter` 后打开就地批注输入；确认后在右侧栏创建浅蓝色批注卡片。

批注记录包含：

- 唯一标识。
- 原文起止偏移。
- 创建时的引用文字。
- 批注正文。
- 创建时间。

批注卡片显示引用文字、批注正文、编辑按钮和删除按钮。编辑与删除只影响该批注，不修改普通备注或答题原文。按 `Esc` 取消当前选择或关闭未提交的批注输入。

### 7.2 原文变化

重新粘贴答题内容后，系统使用引用文字和邻近位置尝试重新定位已有批注。能唯一匹配时更新起止偏移；无法唯一匹配时保留批注卡片并标记为“原文位置已变化”，不绘制错误箭头。

### 7.3 箭头定位

工作区使用一层不拦截鼠标事件的 SVG 连接层。浅色箭头从选中文字末端或批注原文高亮末端出发，连接到右侧对应批注卡片的左侧边缘。

箭头位置在以下事件后重新计算：

- 创建、编辑或删除批注。
- 切换模板或重新排版。
- 页面、答题区或右侧栏滚动。
- 窗口尺寸变化。
- 右侧卡片高度变化。

批注卡片按原文位置排序，并通过最小间距规则避免互相覆盖。目标卡片滚出右侧可视区时隐藏对应箭头；滚回可视区后恢复。减少动态效果模式下仅更新静态位置，不播放路径动画。

## 8. 快捷键

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl/Cmd+Shift+V` | 从剪贴板粘贴文本到答题纸 |
| `Ctrl/Cmd+Enter` | 为当前选中文字打开批注输入 |
| `Esc` | 取消选择或关闭未提交批注 |
| `Ctrl/Cmd+P` | 打开申论专用打印导出 |
| `Alt+1` | 切换 200 字模板 |
| `Alt+2` | 切换 400 字模板 |
| `Alt+3` | 切换 800 字模板 |
| `Alt+4` | 切换 1000 字模板 |

页面控件补充 `aria-keyshortcuts`。输入焦点位于普通备注或批注编辑框时，只拦截 `Esc`，其他组合键保留系统编辑行为。

## 9. 打印与 PDF

“导出 PDF”和 `Ctrl/Cmd+P` 进入浏览器打印流程。打印样式隐藏应用侧栏、页头操作控件、输入框操作按钮和临时选择工具，只保留：

- 当前模板及必要的超限警示行。
- 已排版文字和每 200 字水印。
- 普通备注的渲染结果。
- 批注卡片、原文高亮和连接箭头。

打印输出使用真实 DOM 文字和锚点，不把页面先栅格化，因此中文字体沿用浏览器能力，复盘链接在 PDF 中保留为可点击链接。页面使用分页避让规则，避免批注卡片和单行答题格被截断。

## 10. 组件与职责

建议保持以下边界：

- 申论排版模块：负责字符分类、分词、占格、换行、水印和超限结果，不访问 DOM。
- 备注解析模块：负责安全解析普通文本与内部复盘链接，不访问浏览器路由。
- 申论页面：负责剪贴板、草稿、选择、批注、快捷键和打印入口。
- 箭头连接层：只接收原文锚点与批注卡片元素位置，负责计算和绘制路径。
- 复盘跳转适配：只处理稳定锚点、目标展开和滚动，不改变复盘业务数据。
- 页面样式：负责 25 列稳定尺寸、左右布局、打印、响应式和辅助功能媒体查询。

移动或窄窗口下保持 25 列答题纸的稳定格宽，通过工作区横向滚动保证方格不被压扁；右侧栏移动到答题纸之后，但仍保持普通备注与批注同时显示。

## 11. 验证标准

### 11.1 逻辑测试

- 四种模板生成正确基础行数和 25 列结构。
- 汉字、中文标点、拉丁字母、数字、空格和换行按规则占格。
- 中文词语不被常规换行拆分，标点不单独落在行首。
- 200 字累计位置、水印和超限格计算正确。
- 备注只解析允许的内部链接，其他输入保持纯文本。
- 原文变化后的批注能重新定位或进入明确的失联状态。

### 11.2 页面测试

- 导航顺序、路由、标题和激活状态正确。
- 粘贴成功、权限失败、模板切换、字数刷新和独立清空行为正确。
- 选择文字后可以创建、编辑和删除批注，普通备注不受影响。
- 所有快捷键在页面与输入框焦点条件下行为正确。
- 复盘链接能够展开目标并滚动到稳定锚点。
- 本地草稿可以恢复，损坏草稿安全回退。

### 11.3 视觉与打印验证

- 桌面视口确认 25 列不缺失、不变形、不与右侧栏重叠。
- 窄视口确认横向滚动和右侧下移后文字不溢出。
- 批注箭头在创建、滚动、缩放和模板切换后仍连接正确。
- 减少动态、降低透明度和高对比度设置均有可用回退。
- 打印预览只包含申论交付内容，中文、网格、水印、箭头和链接均可见。

## 12. 并行施工边界

设计确认后按独立文件责任区并行：

1. 排版与备注解析逻辑及其测试。
2. 申论页面、草稿、批注和快捷键及其组件测试。
3. 申论页面视觉、响应式和打印样式及其静态测试。

共享入口文件、复盘页适配、共享导航测试、设计文档和 `progress.md` 由主智能体单写。各责任区不得修改同一文件；主智能体整合后执行完整测试、类型检查、构建、浏览器截图和打印预览验证。
