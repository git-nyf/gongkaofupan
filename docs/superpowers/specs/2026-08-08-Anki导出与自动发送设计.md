# Anki 导出与自动发送设计

## 目标

在现有卡片库和每日 Anki 能力上补齐两个用户闭环：

1. 用户可以在卡片库直接导出 Anki 卡组，并查看、回顾和再次下载历史导出批次。
2. 应用每次启动后检查最近 24 小时是否成功发送过复习卡；若没有，则随机生成并通过 cc-connect 发送 1 张。

本轮不新增数据库表，不修改卡片、题面或复习计划的数据结构。

## 方案选择

采用“文件历史 + 现有设置表”的方案：

- 导出批次保存到 Git 已忽略的 `output/anki/exports/`，每批包含 `.apkg`、Markdown 和 JSON 元数据。
- 最近成功发送时间写入现有 `app_settings`，键名固定为 `anki_last_successful_send_at`。
- 不采用新增导出记录表，避免数据库迁移和备份协议变化。
- 不采用浏览器本地存储，因为后台启动检查无法可靠读取浏览器状态。

## 卡片库导出

### 导出范围

- 用户勾选卡片时，只导出所选卡片对应的用户初始稿。
- 未勾选卡片时，导出全部未归档、AI 状态为可用且包含可靠题面的用户初始稿。
- 同一初始稿衍生出的多张卡片按完整原始内容去重，只保留一个代表题面。
- Anki 正面使用系统已有的 DeepSeek 衍生题面，背面使用完整用户初始稿。

### 文件与稳定编号

每次导出生成独立批次编号，文件名包含本地时间和短编号，避免覆盖历史记录：

```text
output/anki/exports/
  card-library-20260808-093000-a1b2c3.apkg
  card-library-20260808-093000-a1b2c3.md
  card-library-20260808-093000-a1b2c3.json
```

JSON 元数据记录批次编号、生成时间、卡片数量、卡片稳定编号、分类、题面、完整答案和两个导出文件名。文件路径由服务端根据受控编号拼接，不接受客户端传入任意路径。

### 接口

- `POST /api/anki/exports`：创建导出批次；可选接收 `cardIds`，为空时导出全部符合条件的初始稿。
- `GET /api/anki/exports`：按时间倒序返回历史批次摘要。
- `GET /api/anki/exports/:id`：返回单个批次及卡片内容，用于回顾。
- `GET /api/anki/exports/:id/apkg`：重新下载历史 `.apkg`。

没有可用卡片时返回稳定的空结果，不创建空文件。损坏或缺失的单个历史元数据文件会被跳过，不阻断其他历史记录。

## 卡片库交互

卡片库现有导出区域增加两个图标加文字按钮：

- `导出 Anki`：有勾选时显示所选数量；执行期间禁用，成功后自动下载 `.apkg` 并显示导出数量。
- `导出记录`：从页面底部打开历史面板，保持现有浅色液态玻璃风格，背景不模糊。

历史面板按时间倒序展示批次时间和卡片数量。点击批次后在同一底部面板展示题面、分类和完整答案，并提供再次下载按钮。面板支持关闭按钮和 `Esc`，关闭后焦点返回触发按钮；减少动态效果模式下取消弹簧位移动画。

## 启动后自动发送

### 判定流程

应用服务启动完成后异步执行一次检查：

1. 读取 `app_settings.anki_last_successful_send_at`。
2. 若时间有效且距当前时间不足 24 小时，直接跳过。
3. 若不存在、无效或已经超过 24 小时，随机抽取 1 张符合条件的用户初始稿。
4. 生成独立的单卡 Markdown 与 `.apkg`，通过现有 cc-connect 发送器发送。
5. 只有发送器返回成功时，才把当前时间写入 `app_settings`。

检查使用进程内共享 Promise 防止同一进程的重复触发并发发送。自动发送失败、没有可用题面或 cc-connect 未运行时，不写成功时间，也不阻断服务启动。

### 文件隔离

自动单卡文件使用 `auto-review-<本地时间>-<短编号>` 前缀，避免覆盖每日十张卡组和卡片库手动导出历史。

## 错误处理

- 导出失败：页面保留原选择和筛选状态，显示稳定错误提示。
- 历史读取失败：历史面板显示错误，不影响卡片库主体。
- 再次下载文件缺失：返回 404，不泄露服务器路径。
- 自动发送失败：只记录服务端错误摘要，不记录卡片正文和 cc-connect 凭据。
- cc-connect 未绑定或后台停止：保留生成文件，下次应用启动仍会重新检查。

## 验证标准

- 勾选卡片时只导出对应初始稿；未勾选时导出全部合格初始稿。
- 同一初始稿不会在一个批次中重复出现。
- 每次手动导出生成独立批次，历史列表可查看题面、完整答案并重新下载。
- 最近成功发送时间不足 24 小时时不调用发送器。
- 超过 24 小时或没有成功记录时只发送 1 张；失败不更新时间，成功才更新时间。
- 自动发送不覆盖现有每日卡组或手动导出历史。
- 新增服务端和前端测试先失败后修复，定向测试、类型检查和构建通过；完整测试中的既有无关失败单独记录。

## 非目标

- 本轮不接入 AnkiWeb 或 AnkiConnect。
- 本轮不提供历史批次删除、重命名或云同步。
- 本轮不改变现有 FSRS 到期判断和背诵记录。
- 本轮不自动完成 cc-connect 的微信扫码授权。
