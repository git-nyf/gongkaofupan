# 公考记忆卡基础版设计

## 一、业务结论

本项目建设一款面向公务员考试备考的本地记忆卡工具，工作名为“公考记忆卡”。首版采用桌面优先的响应式网页形态，以“快速录入、AI 自动规范、混合抽卡、间隔复习、薄弱复盘”为唯一业务闭环。

首版为单人本地应用，不设置账号体系，不依赖 MySQL，不提供云同步。数据使用 SQLite 保存，图片保存在本机数据目录。用户输入可以是口语、短句、等号关系或完整错题；本机后端调用 DeepSeek V4 Flash，将原文自动整理为统一卡片字段，并生成可直接背诵的单向或双向题面。

产品不照搬单词软件的“词面—释义”模型，而是围绕公考多板块、多字段、错因、解析、口诀和复习方向组织数据。

## 二、目标与成功标准

### 2.1 产品目标

1. 用户能用不规范口语快速记录，不必先把内容整理成标准题目。
2. 系统能自动保留原文、生成规范表述，并在明确对应关系下生成双向背诵题。
3. 用户能按多个公考板块、星级、标签、掌握程度混合抽卡。
4. 每次背诵结果能更新题面复习时间，并汇总到卡片级薄弱数据。
5. 用户能在总览和复盘页直接找到今日到期卡片、薄弱板块与高频错题。
6. 数据在应用重启后仍然存在，并可完成本地备份和恢复。

### 2.2 首版验收标准

1. 一条本地命令启动前端和后端，浏览器可直接访问。
2. 能新增、编辑、删除、搜索、筛选、归档卡片。
3. 输入“广陵=扬州”后，无需二次确认，系统自动生成“广陵=？”和“扬州=？”两个题面。
4. 用户能选择至少两个板块生成随机混合卡组，并完成翻卡和掌握程度标记。
5. “完全不会、记忆模糊、熟练掌握”能分别更新错题数据和下次复习时间。
6. 总览不展示近七天学习量，只展示今日到期、今日新增、待攻克卡片和薄弱板块。
7. API Key 不出现在前端代码、接口响应、SQLite、备份文件、运行日志或版本库中。
8. DeepSeek 不可用时，原始输入仍能保存并显示“待整理”，恢复联网后可以重试。
9. 在 1440×900 和 1024×768 两种桌面视口下，核心页面无内容遮挡、按钮溢出或不可操作区域。

## 三、已确认的产品决策

| 决策项 | 确认结果 |
| --- | --- |
| 首版交付 | 可实际录入和背诵、数据本地保存的可运行基础版 |
| 运行平台 | 本地响应式网页 |
| 主要设备 | 电脑录入和电脑背诵，不要求手机可用 |
| 数据库 | SQLite，不使用 MySQL |
| 使用方式 | 单人、本地、无需登录 |
| 主布局 | 紧凑侧栏工作台 |
| 视觉方向 | 炭灰与朱红，白色内容区，圆角不超过 6 像素 |
| AI 服务 | DeepSeek OpenAI 兼容接口，模型固定为 `deepseek-v4-flash` |
| AI 交互 | 保存后自动整理并直接入库，不要求用户二次确认 |
| 事实约束 | 只整理原文，不补充、纠正或改写事实结论 |
| 复习调度 | 使用 `ts-fsrs`，不手写固定天数表 |
| 趋势数据 | 首版不展示近七天学习量、连续天数等活跃度图表 |

## 四、范围与分期

### 4.1 首版范围

- 卡片录入、编辑、删除、归档和全文检索。
- 公考板块和二级考点多选。
- 错题录入、知识点积累两种模式。
- 七套标准化录入模板。
- 基础受控富文本：加粗、文字颜色、分段、图片插入、预置公式文本插入。
- DeepSeek 自动结构化、单向题生成、明确关系双向题生成。
- 星级、标签、掌握程度、错题次数。
- 多板块筛选、到期优先、随机混合抽卡。
- 翻卡、答案遮罩、上一张、下一张。
- FSRS 间隔复习调度。
- 总览、薄弱板块、高频错题和一轮背诵结果。
- SQLite 与本地图片备份、恢复。

### 4.2 首版不做

- 语音转文字。
- Excel 批量导入。
- PDF、图片、文本批量导出与分享。
- 云端同步、账号、多设备登录。
- 系统级定时通知。
- 手写批注。
- 文件夹、多卡关联、同屏对比。
- 倒计时、闯关动画和复杂成就体系。
- 自动查重和批量清理。
- 月度报告和长期学习量曲线。
- 手机端专项适配。

## 五、信息架构

### 5.1 主导航

侧栏固定六个一级入口：

1. **总览**：今日到期、今日新增、待攻克卡片、薄弱板块。
2. **录入**：模式切换、模板选择、自由输入、结构化字段和图片。
3. **背诵**：范围筛选、卡组生成、翻卡和掌握标记。
4. **卡片库**：搜索、筛选、编辑、归档和批量操作。
5. **复盘**：薄弱板块和高频错题。
6. **设置**：默认背诵偏好、DeepSeek 连接状态、备份和恢复。

### 5.2 核心流程

**积累流程：**

刷题遇到错题或积累考点 → 选择板块、考点与模板 → 输入口语化原文 → 保存原文 → DeepSeek 自动规范 → 生成题面 → 写入卡片库。

**复习流程：**

选择多个板块和数量 → 到期题面优先并随机补齐 → 查看题面并思考 → 翻卡查看答案 → 标记掌握程度 → FSRS 更新到期时间 → 更新错题与薄弱数据 → 在复盘页进入专项背诵。

## 六、六大功能模块

### 6.1 录入编辑模块

#### 基础刚需功能

1. 支持以下一级板块多选：言语理解、常识判断、政治理论、图形推理、定义判断、类比推理、逻辑判断、资料分析、数量关系、申论素材。
2. 二级考点按以下清单内置，不允许 AI 覆盖用户手动选择：
   - 言语理解：逻辑填空、主旨概括、意图判断、细节理解、语句排序、语句填空、下文推断。
   - 常识判断：法律、党史、文史、科技、地理、经济、生活常识。
   - 政治理论：马原、毛中特、新时代中国特色社会主义思想、时政会议、政策金句、党内法规。
   - 图形推理：位置规律、样式规律、数量规律、属性规律、空间重构、特殊图形特征。
   - 定义判断：关键词抓取、主体客体、条件结果、限定陷阱。
   - 类比推理：语义关系、逻辑关系、语法关系、二级辨析坑点。
   - 逻辑判断：翻译推理、真假推理、削弱加强、前提假设、排列组合。
   - 资料分析：基础公式、速算技巧、同比环比、比重、平均数、倍数、单位陷阱、时间陷阱、计算易错点。
   - 数量关系：工程、行程、利润、容斥、排列组合、概率、几何。
   - 申论素材：规范词、人物素材、政策金句、作文分论点。
3. 提供“错题录入”和“知识点积累”两种模式。
4. 提供七套标准模板，模板只预填字段结构和提示语，不写入虚构内容。
5. 所有卡片均具有以下固定字段：所属板块、细分考点、题干或核心知识点、错误选项或易错点、正确解析、记忆速记口诀、同类拓展知识点、题目来源、录入日期、补充笔记。
6. 用户保存时只需手填所属板块、细分考点、原始输入。卡片进入背诵卡组前必须同时具有非空正确解析；正确解析可以由用户填写，也可以由 AI 根据原文生成。其余字段允许为空。
7. 支持加粗、文字颜色、分段、插入本地图片和插入预置公式文本。
8. 保存时先持久化原始输入，再调用 DeepSeek 自动规范。
9. 自动规范不弹出确认页；完成后直接更新卡片并生成背诵题面。
10. 编辑卡片时同时显示规范内容和原始输入，用户可手动纠正规范内容；编辑“待完善”卡片并保存后，系统自动重新调用 AI 整理。

#### 进阶增值功能

1. 语音录入和自动转文字。
2. Excel 批量导入与字段映射。
3. 公式快捷输入库扩展和数学公式编辑器。
4. 多卡关联与跨板块跳转。
5. 多卡批量修改板块、标签、星级与掌握状态。
6. 手写批注。

### 6.2 背诵自测模块

#### 基础刚需功能

1. 支持多个板块同时选择，也支持单板块专项背诵。
2. 支持按星级、标签、录入时间和掌握程度补充筛选。
3. 支持 10、20、50 和自定义数量。
4. 默认优先加入到期题面，不足数量时从所选范围随机补齐。
5. 支持随机混排和固定顺序。
6. 卡片正面只显示题面，答案默认遮罩；点击后显示答案、规范知识、解析、口诀、拓展和笔记。
7. 支持上一张、下一张、收藏、标签和归档快捷操作。
8. 翻卡后必须选择完全不会、记忆模糊或熟练掌握，才能完成本题记录。
9. 一个知识卡可以有多个题面；正向和反向题面分别调度，卡片整体掌握度取所有有效题面中的最低等级。
10. 一轮结束只展示完成数量、三类掌握结果和薄弱考点。

#### 进阶增值功能

1. 保存自定义混合背诵方案和板块配额。
2. 根据长期错题数据调整随机权重。
3. 单卡 10、30、60 秒倒计时。
4. 10、20、50、100 张闯关模式和关卡动画。
5. 系统级到期通知。
6. 多卡对比背诵。

### 6.3 卡片收藏管理模块

#### 基础刚需功能

1. 一至五星优先级。
2. 单卡多标签。
3. 完全不会时累计一次错误；记忆模糊记录为薄弱但不增加错误次数。
4. 完全不会、记忆模糊、熟练掌握三级状态。
5. 卡片库使用紧凑表格，显示规范知识、板块、星级、掌握度、错误次数和下次复习时间。
6. 支持搜索原始输入、规范内容、解析、口诀、拓展和标签。
7. 支持按板块、星级、掌握程度、标签、归档状态和 AI 整理状态筛选。
8. 支持批量加星、添加标签和归档。
9. 归档题面不进入自动抽卡，仍可在卡片库中调出。

#### 进阶增值功能

1. 自建文件夹与跨文件夹调取。
2. 多卡绑定与关联跳转。
3. 批量删除重复卡片。
4. 自动相似度查重。
5. 归档黑名单细分规则。

### 6.4 数据复盘模块

#### 基础刚需功能

1. 总览显示今日到期、今日新增和待攻克卡片数量。
2. 按板块统计完全不会、记忆模糊和错误次数，生成薄弱板块排序。

2. 五星错题、高频坑点、未掌握知识点汇总。
3. PDF、文本和图片导出。

### 6.5 拓展辅助模块

## 七、录入页设计

### 7.1 布局

录入页采用主内容区加右侧属性栏：

- 顶部：录入模式和模板选择。
- 主内容区：原始输入、题干或知识点、易错点、正确解析、口诀、拓展和补充笔记。
- 右侧属性栏：所属板块、细分考点、题目来源、星级、掌握程度、标签和录入日期。
- 顶部右侧：取消和“保存并自动整理”。

### 7.2 保存顺序

1. 校验所属板块、细分考点和原始输入。
2. 使用事务 A 写入原始卡片、用户分类、用户标签和附件记录，状态为“整理中”，随后立即提交。
3. 本机服务调用 DeepSeek。
4. 校验返回 JSON。
5. 使用事务 B 原子更新规范字段、AI 标签和题面，状态改为“已整理”，随后提交。
6. 如果 AI 判断原文没有足够信息形成安全问答，事务 B 保存规范原文和正确解析，状态改为“待完善”，不生成题面。
7. 如果 AI 调用或结构校验失败，保留原文，使用补偿事务把状态改为“待整理”，不生成可背诵题面。
8. 后端在应用启动时重新处理待整理卡片；用户可以对待整理和待完善卡片手动触发重试。编辑待完善卡片并保存后自动重新整理。启动时把持续“整理中”超过五分钟的记录回收为“待整理”。

DeepSeek 网络调用处于两个数据库事务之外，不持有长事务。事务 A 成功后，即使 AI 或事务 B 失败，原始输入也不会丢失。

## 八、DeepSeek 自动整理设计

### 8.1 接口约束

- 基础地址：`https://api.deepseek.com`
- 接口：`POST /chat/completions`
- 模型：`deepseek-v4-flash`
- 思考模式：关闭。
- 返回格式：`json_object`。
- API Key：只读取本机环境变量 `DEEPSEEK_API_KEY`。
- 浏览器不直接调用 DeepSeek。

用户在对话中暴露过一枚密钥，该密钥不得使用，必须在 DeepSeek 控制台撤销并重新生成。新密钥只允许由用户写入本机 `.env`，不得进入聊天、源码或日志。

### 8.2 严格系统提示词

```text
你是公务员考试记忆卡结构化工具，不是知识问答助手。

你的唯一任务是将用户输入整理为便于复盘和背诵的结构化 JSON。

必须遵守：
1. 只使用用户原文明确表达的信息，不得补充、纠正、推测或扩展任何事实。
2. 人名、地名、时间、数字、比例、公式、否定词、条件和范围必须原样保留。
3. 允许统一标点、删除口头语、拆分字段和改写为简洁问句，但不得改变结论含义。
4. 只有原文明确表示等号、对应、互为别称或双向关系时，才能生成两个方向的题面。
5. 因果、条件、定义、结论、公式和普通题目默认只生成单向题面，不得为了凑双向题而反推。
6. 无法从原文安全确定问题与答案时，normalized_statement 和 analysis 使用清理标点后的原文，question_type 使用 unstructured，quiz_items 返回空数组，不得猜测。
7. 用户手动选择的板块和细分考点只作为组织信息，不得被覆盖。
8. 标签只能描述原文已有主题或用户已选分类，不得写入新的事实判断。
9. 只输出 JSON，不输出解释、Markdown 或思考过程。
```

  "template": "所选模板名称",

    "extension": "用户已填内容或空字符串",

  }
}
```

  "extension": "",
  "notes": "",
  "tags": ["地名对应"],
  "quiz_items": [
    {
      "direction": "forward",
      "question": "广陵=？",
      "answer": "扬州"
    },
    {
      "direction": "reverse",
      "question": "扬州=？",
      "answer": "广陵"
    }
  ]
}
```

### 8.6 校验与重试

1. 后端用固定模式校验返回字段、枚举值、题面数量和字符串长度。
2. `single` 必须恰好有一个题面；`bidirectional` 必须恰好有两个题面，方向分别为 `forward` 和 `reverse`；`unstructured` 不得包含题面。
3. 正确解析不得为空；`single` 和 `bidirectional` 的问题、答案不得为空。如果原文是简单等号关系，正确解析使用原始关系本身。
4. JSON 为空、截断或结构错误时立即重试一次。
5. 第二次仍失败时标记为待整理，保存错误类型，不保存完整第三方响应。
6. 日志只记录卡片编号、耗时、结果状态和错误码，不记录原文、返回正文或 API Key。

## 十、背诵与调度规则

### 10.1 卡组生成

1. 用户选择板块、星级、标签、录入时间、掌握程度和数量。
2. 排除归档、AI 待整理和没有有效题面的卡片。
3. 优先取所选范围内已到期题面。
4. 到期题面不足时，从剩余范围随机补齐。
5. 正向和反向题面是两个独立候选项，同一轮默认不重复出现同一题面。
6. 固定顺序按录入时间和题面创建顺序排列。

### 10.2 掌握等级映射

| 用户选择 | FSRS 评分 | 业务结果 |
| --- | --- | --- |
| 完全不会 | 再次学习 | 题面复习间隔缩短，卡片错误次数加一 |
| 记忆模糊 | 困难 | 题面安排较近复习，卡片进入薄弱统计 |
| 熟练掌握 | 良好 | 题面复习间隔延长 |

首版不提供“轻松”第四档，避免增加判断负担。卡片级掌握度取所有未归档题面的最低等级，避免正向熟练掩盖反向薄弱。

## 十一、卡片库与复盘规则

### 11.1 搜索

首版使用 SQLite 参数化查询，对原始输入、规范内容、解析、口诀、拓展、笔记和标签做包含匹配。数据规模未达到性能瓶颈前不引入全文检索索引和搜索服务。

### 11.2 薄弱板块

板块薄弱度只依据真实复习记录计算：

- 完全不会次数权重最高。
- 记忆模糊次数权重次之。
- 没有复习记录的卡片不进入错误率计算。
- 熟练掌握不会直接抹除历史错误，但会影响当前待攻克数量。

具体排序优先使用“完全不会次数 × 2 + 记忆模糊次数”，并同时显示涉及卡片数。该分数用于排序，不宣称为考试正确率。

### 11.3 高频错题

按卡片累计“完全不会”次数降序展示；次数相同则最近一次错误更近者优先。点击卡片可直接生成该卡及同考点的专项卡组。

## 十二、技术架构

### 12.1 前端

- React、TypeScript、Vite。
- React Router 管理六个一级页面。
- Lucide 图标用于导航和工具按钮。
- 不引入大型组件框架；使用局部组件和统一设计变量。
- 页面以 1024 像素为最低桌面宽度，不承诺手机操作体验。

### 12.2 本机后端

- Node.js、TypeScript、Express。
- 原生 `fetch` 调用 DeepSeek OpenAI 兼容接口。
- Zod 校验接口输入和 AI JSON。
- `better-sqlite3` 访问 SQLite，并启用 WAL。
- `ts-fsrs` 计算题面复习状态。
- 开发环境由一条脚本同时启动前端和后端；生产构建由后端提供静态网页。

## 十三、安全与异常处理

### 13.1 API Key

1. `.env` 必须加入 `.gitignore`。
2. 仓库只提供不含真实值的 `.env.example`。
3. 后端只读取 `DEEPSEEK_API_KEY`，不得提供读取密钥的接口。
4. 前端只获得 `configured: true/false`。
5. 备份和日志不得包含环境变量。

### 13.2 AI 异常

1. 设置明确超时。
2. 空响应、非法 JSON、字段缺失和题面数量不符时重试一次。
3. 仍失败则卡片状态为待整理，原文不丢失。
4. 待整理卡片不进入背诵卡组，避免出现空答案或错误题面。
5. 用户可以在卡片库查看失败状态并手动触发重试。

### 13.3 数据异常

1. 原始卡片、用户分类、用户标签和附件记录在事务 A 中写入并提交；AI 规范字段、AI 标签、题面和最终状态在事务 B 中原子写入。DeepSeek 网络调用不得处于数据库事务内。事务 B 失败时使用独立补偿事务把卡片改为“待整理”；启动时把持续“整理中”超过五分钟的记录回收为“待整理”。
2. 删除卡片时同步删除关联题面、标签关系和附件记录；本地图片在事务成功后删除。
3. 恢复备份前校验清单、数据库版本和文件路径。
4. 恢复前自动生成当前数据副本；恢复失败则保留原数据。
5. 上传只接受常用图片格式，并设置单文件大小上限。

## 十四、完整使用闭环

1. 用户刷题遇到错题或积累零散考点。
2. 进入录入页，选择错题或知识点模式。
3. 选择板块、细分考点和模板。
4. 用口语、短句、等号关系或完整题目输入原文，可附图片。
5. 设置星级、标签和初始掌握程度。
6. 点击保存，系统先保存原文，再自动调用 DeepSeek 规范字段并生成题面。
7. 用户进入背诵页，选择多个板块、数量和筛选条件。
8. 系统优先抽取到期题面，并随机补齐本轮数量。
9. 用户先看题面思考，再翻卡查看答案、解析、口诀和拓展。
10. 用户标记完全不会、记忆模糊或熟练掌握。
11. 系统使用 FSRS 更新每个题面的下次复习时间，并更新卡片错误次数和薄弱状态。
12. 用户在总览查看今日到期，在复盘查看薄弱板块与高频错题。
13. 用户从薄弱板块或高频错题进入专项背诵。
14. 连续熟练且暂时无需复习的卡片可以归档。
15. 用户定期导出本地备份包，保护 SQLite 数据和图片。

## 十五、核心差异化优势

1. **输入门槛不同。** 普通单词软件要求先整理好词面与释义；本产品允许直接输入口语和错题碎片，由 AI 自动整理。
2. **知识结构不同。** 单词软件通常是一正一反两个文本字段；本产品保留板块、考点、错因、解析、口诀、拓展、来源、图片和笔记。
3. **题面方向不同。** 明确对应关系可以自动生成正反题面，复杂题目仍保持单向逻辑，不强行反问。
4. **复习范围不同。** 支持言语、常识、政治、判断、资料、数量和申论跨板块混合抽卡。
5. **薄弱判断不同。** 依据实际“完全不会”和“记忆模糊”记录定位板块短板，不用学习时长替代掌握效果。
6. **部署方式不同。** 首版本地运行，SQLite 和图片由用户掌控；除主动调用 DeepSeek 的卡片文本外，不依赖云端数据服务。

- 卡片翻转、加载和 AI 整理状态不会导致布局跳动。

## 十七、风险与控制

| 风险 | 控制方式 |
| --- | --- |
| AI 改变原意 | 严格提示词、结构校验、保留原文、允许后续手动纠正 |
| API 不可用 | 原文先入库、待整理状态、一次自动重试和手动重试 |
| 密钥泄露 | 环境变量、服务端代理、日志脱敏、备份排除、版本库忽略 |
| 本地数据丢失 | SQLite 一致性备份、图片打包、恢复前自动副本 |
| 双向题互相掩盖 | 每个方向独立 FSRS 状态，卡片状态取最弱方向 |
| 首版范围失控 | 只实现本设计 4.1，4.2 和各模块进阶功能不进入首版施工 |
