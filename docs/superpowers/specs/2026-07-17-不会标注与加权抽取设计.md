# 不会标注与加权抽取设计

## 一、业务结论

公考记忆卡不再让用户选择星级、熟练度或“完全不会、记忆模糊、熟练掌握”三档结果。用户遇到不会的知识点时点击“不会 +1”，系统累计卡片级不会标注次数，并在随机抽卡时提高它的出现机会。

“不会 +1”成功后才揭示答案，显示新次数并停留当前题，由用户手动进入下一张。用户主动查看答案时，可以选择“不会 +1”或“记住了”。两种结果继续驱动现有 FSRS 调度，但内部等级不在用户界面或外部接口中暴露。

本设计复用 `cards.wrong_count`，不迁移数据库，不改变历史复习日志结构。

## 二、覆盖关系与成功标准

本文件定向覆盖《2026-07-16-公考记忆卡基础版设计》中以下冲突条款：

- 星级的录入、显示、筛选、批量修改和背诵过滤。
- 掌握度、熟练度及三档掌握结果的录入、显示、筛选、操作、汇总和验收。
- 基于星级或掌握度的随机抽取、薄弱判断、总览、复盘和设置。

其他产品范围、AI 整理、数据安全、备份恢复和本地运行约束继续有效。发生冲突时以本文件为准。

交付必须同时满足：

1. 六个一级页面、详情抽屉、筛选、表格、表单、弹层、提示和无障碍名称均不出现星级、熟练度、掌握度或三档选择。
2. 每次“不会 +1”成功后卡片计数恰好增加一，正反题面共享该值。
3. 不会结果的调度、日志和计数加一原子提交；记住结果的调度和日志原子提交且不加次数。
4. 不会标注成功后揭示答案、显示新次数、停留当前题，本轮当前题面不能重复提交。
5. 随机顺序按不会标注次数加权且题面不重复；固定顺序不使用权重。
6. 旧 SQLite 数据无需迁移即可启动、查询、复习、备份和恢复。

## 三、数据语义与兼容边界

### 3.1 不会标注次数

用户可见名称统一为“不会标注”或“不会标注次数”，不得显示“错误次数”。

- `cards.wrong_count` 是卡片级计数，新卡沿用默认值零。
- 任一题面提交不会成功后，所属卡片计数加一。
- 同卡单向、正向和反向题面读取同一值。
- 归档、编辑、AI 重整或题面重建不清零。
- 不提供手工加减、清零或批量改写入口。

### 3.2 旧字段保留

`cards.rating`、`cards.mastery`、`quiz_items.mastery`、`review_logs.rating` 和现有 FSRS 字段继续保留，仅用于无迁移兼容、内部调度和历史读取。新界面不提供读写入口，新建数据由数据库默认值填充旧字段，外部响应不得透传它们。

### 3.3 外部复习契约

```ts
interface ReviewInput {
  quizItemId: string;
  result: 'unknown' | 'known';
}

interface ReviewResult {
  quizItemId: string;
  cardId: string;
  result: 'unknown' | 'known';
  nextDueAt: string;
  wrongCount: number;
}
```

路由校验后在服务边界执行固定映射：

| 外部结果 | 内部 FSRS 结果 | 计数变化 |
| --- | --- | --- |
| `unknown` | `again` | 加一 |
| `known` | `good` | 不变 |

外部不再接受 `rating` 或 `hard`。`review_logs.rating` 继续写入映射后的 `again` 或 `good`；历史 `hard` 不删除、不改写。响应不返回 `rating`、`quizMastery` 或 `cardMastery`。

### 3.4 其他外部契约

- `CardDetail` 保留 `wrongCount`，删除 `rating`、`mastery`。
- `StudyItem` 增加 `wrongCount`，删除 `rating`、`mastery`。
- `CreateCardInput` 删除 `rating`、`initialMastery`。
- `CardUpdateInput`、`CardSearchInput` 删除 `rating`、`mastery`。
- `BulkCardUpdateInput` 删除 `rating`。
- `StudySessionInput` 删除 `rating`、`mastery`。

服务端 Zod 模式、查询参数和 SQL 筛选同步收敛，严格拒绝废弃字段。仓储内部行类型可以保留旧字段，但必须显式映射外部对象。

## 四、事务规则

### 4.1 不会

`POST /api/reviews` 收到 `unknown` 后，在一个 SQLite 事务中：

1. 查询题面及卡片，不存在则返回 `404 not_found`。
2. 映射为 `again`，用现有 FSRS 调度器计算并更新题面状态。
3. 向 `review_logs` 写入 `again`、原到期时间、新到期时间和复习时间。
4. 执行 `cards.wrong_count = cards.wrong_count + 1` 并更新卡片修改时间。
5. 读取并返回新 `wrongCount`。

任一步失败均回滚调度、日志和计数。

### 4.2 记住了

`known` 在同一事务结构中映射为 `good`，更新调度并写入日志，不增加次数，响应返回原 `wrongCount`。

### 4.3 重复提交边界

本轮不新增数据库幂等表。前端按当前会话的 `quizItemId` 保存已成功题面，请求开始立即锁定两个结果操作，成功后保持锁定，失败后解除并允许重试。该规则防止当前界面双击，不承诺跨窗口去重。

## 五、背诵交互

### 5.1 正面

正面显示题目、“不会标注 N 次”状态、“不会 +1”按钮、“查看答案”按钮及现有导航。状态文本与命令按钮必须分开，不能合并为含义不清的徽章。

### 5.2 点击“不会 +1”

1. 立即禁用当前题面的结果操作并显示“正在记录”。
2. 成功后以服务端值更新次数、揭示答案，显示“已标注不会，本卡共 N 次”。
3. 不自动前进；“下一张”保持可用，由用户手动继续。
4. 当前会话返回该题面时保持已提交状态，不能重复标注。
5. 失败时次数不变；未翻面则保持正面，已翻面则保持答案。就近显示错误并恢复重试。

### 5.3 主动查看答案

“查看答案”只揭示答案，不写日志、不更新调度。答案区提供互斥的“不会 +1”和“记住了”。任一成功后都停留当前题并锁定两项结果；失败后保持答案并允许重试。

上一张和下一张不强制提交，未提交题面可跳过。轮次完成数按成功提交题面计，不按浏览数计。结束页只展示已记录题面数、本轮不会次数、本轮记住次数和高标注考点，不展示三档结果或熟练比例。

## 六、随机抽取规则

### 6.1 候选范围

沿用现有规则排除归档、未整理完成及无有效题面的卡片，再应用板块、标签、卡片编号和录入时间筛选。星级和掌握度不参与查询。每个题面是独立候选项，同轮不重复 `quizItemId`。

### 6.2 权重与同卡题面

```text
卡片权重 = 1 + wrong_count
题面权重 = (1 + wrong_count) / 当前候选池内该卡片的题面数
```

题面数在候选池开始抽取时确定，选中并移除题面后不重新分配剩余权重。由此正反题面在当前池平分卡片权重，不因题面更多而放大整卡机会。

### 6.3 随机、到期与固定顺序

- 随机且开启到期优先：先建立到期池并加权不放回抽取；不足时再建立未到期池，重新按该池题面数平分权重后补齐。
- 随机且关闭到期优先：在全量候选池加权不放回抽取。
- 加权抽取使用现有可注入随机数源，按权重区间选中后移除题面；不得复制高权重题面再洗牌。
- 固定顺序完全忽略 `wrong_count`，继续按卡片录入时间、题面创建时间和题面编号稳定排序；开启到期优先时先稳定排列到期池，再补未到期池。

`wrong_count = 0` 时卡片权重为一。候选不足时返回全部候选，不制造重复项。随机数为零命中首个正权重区间，接近一命中最后区间。

## 七、页面改动

### 7.1 录入与卡片库

- 录入页删除星级、掌握程度的控件、状态、校验、回填和提交；七套模板不再声明相关公共字段。
- 编辑旧卡时忽略旧字段，不展示也不覆盖。
- 卡片库删除星级与掌握度筛选、列、URL 参数及批量星级操作。
- “错误次数”统一改为“不会标注”，详情抽屉显示“不会标注次数”。
- 搜索、板块、标签、归档、AI 状态、日期、分页、批量标签和批量归档保持。

### 7.2 背诵、总览与复盘

- 背诵页删除星级和掌握度筛选，使用第五节组件；随机顺序自动加权，不提供开关。
- 总览保留今日到期和今日新增；待攻克、薄弱板块按不会标注记录计算，不读卡片 `mastery`，单位明确为“次”。
- 复盘将高频错题改称“高频不会标注”，按 `wrong_count` 降序，同数时按最近内部 `again` 日志时间排序。
- 薄弱板块只统计不会标注及涉及卡片数；历史 `hard` 保留但不计入新版可见指标。
- 专项背诵保持，随机专项卡组同样应用新权重。

### 7.3 设置与文档

设置保留默认数量、默认顺序、到期优先、DeepSeek 状态、备份和恢复。不增加加权开关：随机固定加权，固定顺序固定不加权。使用文档解释不会标注、两种复习动作和随机规则，不向用户解释内部等级。

## 八、错误、无障碍与响应式

- 非法 `result` 返回 `400 invalid_request`；题面不存在返回安全的 `404`；事务失败返回通用 `500`。
- 前端失败时保留题面、翻面状态、筛选和会话位置，不把本题计为完成。
- 操作均用原生按钮和唯一可读名称；次数变化及成功、错误由 `aria-live="polite"` 播报。
- 请求中使用真实 `disabled` 并提供文字状态，不能只依赖颜色或图标。
- 答案展开和状态更新不得丢失焦点；键盘可完成翻面、结果提交、导航和结束本轮。
- 1440×900 与 1024×768 下无重叠、裁切或页面横向滚动；按钮可换行但文字完整，卡片库只允许必要的表格内部受控滚动。

5. 验证 `unknown` 原子更新调度、`again` 日志和计数；`known` 原子更新调度与 `good` 日志但计数不变。

7. 用含历史 `hard`、旧 `mastery` 和非默认 `rating` 的数据库验证无迁移启动与复习。

3. 验证查看答案不发复习请求；“记住了”成功后计数不变并停留。
4. 新建正反题面卡片，在一面标注不会后手动下一张，另一面显示同一新计数。
5. 用可控随机数验证高计数卡区间更大、题面不重复；固定顺序不受计数影响。
6. 在录入、卡片库、背诵、总览、复盘和设置完成浏览器验收。
7. 在 1440×900 与 1024×768 截图并操作，确认无重叠、裁切、页面横向滚动或不可达按钮。
