# 全站 iOS 液态玻璃设计规格

## 状态

- 视觉方向：已批准 A「全面玻璃化」。
- 适用范围：总览、录入、背诵、卡片库、复盘、设置，以及全站侧栏、按钮、表单、抽屉、弹窗和已有拖拽交互。
- 设计依据：`apple-design` 中的即时响应、直接操控、可中断弹簧、速度传递、动量投射、空间一致性、材质层级和辅助功能规则。

## 目标

1. 将现有政务红、国徽、项目图片和学习工作台整体改造成 iOS 风格的全面液态玻璃界面。
2. 让按钮在按下瞬间响应，让拖拽内容与指针一比一跟随，让释放后的运动继承手势速度并可随时重新抓取反向。
3. 让抽屉、弹窗、浮动工具条和内容卡通过不同玻璃厚度表达层级，不依赖普通白底卡片堆叠。
4. 同时支持减少动态效果、减少透明度和高对比度，不以视觉效果牺牲长时间背诵与资料阅读的可读性。

## 非目标

- 不修改数据库结构、后端接口、卡片数据、复盘图片目录或业务流程。
- 不给没有业务含义的卡片增加拖拽、重排或删除能力。
- 不增加背景粒子、彩色光球、循环漂浮装饰、声音或浏览器振动。
- 不把界面改成与现有国徽、政务红和公考语境无关的通用蓝紫色 Apple 仿制主题。

## 视觉语言

### 品牌与色彩

- 保留政务红 `#c64232` 作为主要操作色，成功、警告和错误继续使用现有语义色。
- 页面背景继续读取 DIY 背景；没有自定义背景时使用中性浅灰画布，保证透明材质后方存在可感知的空间深度。
- 深色侧栏改为深色玻璃，不再依赖大面积纯黑；国徽保持第一视觉信号。
- 玻璃表面的颜色来自背景混合、白色亮边和中性阴影，禁止使用大面积紫蓝渐变。

### 玻璃层级

| 层级 | 用途 | 目标材质 |
| --- | --- | --- |
| 薄玻璃 | 按钮、标签、分段控件、输入框、图标工具 | 较低不透明度、约 14px 模糊、轻亮边、短阴影 |
| 标准玻璃 | 页面内容区、统计卡、表单区、日历、复盘板块 | 中等不透明度、约 22px 模糊、双侧亮边、标准阴影 |
| 厚玻璃 | 抽屉、弹窗、全屏查看器工具层 | 较高不透明度、约 30px 模糊、更深阴影和更明确轮廓 |
| 深色玻璃 | 侧栏和深色结构层 | 深灰半透明底、约 24px 模糊、浅色内边和高对比文字 |

全面玻璃化不等于所有节点重复执行模糊。标准玻璃内部的按钮和小标签只使用半透明填充、亮边和阴影，不再叠加独立 `backdrop-filter`，避免双重模糊导致文字和性能下降。

### 形状与排版

- 页面大表面圆角为 20px 到 26px，抽屉和弹窗为 26px 到 30px，小控件为 12px 到 16px；真实内容卡不使用夸张胶囊形。
- 继续使用系统字体和光学字形；正文保持正常字距，标题通过字号、字重和行高建立层级。
- 所有主要触控目标至少为 44px，图标按钮只显示熟悉图标并保留提示与无障碍名称。

## 前端结构

### 样式令牌

在 `src/styles/tokens.css` 增加以下语义令牌：

- 薄、标准、厚、深色玻璃背景与实色回退。
- 玻璃亮边、强边、内高光和四级阴影。
- 模糊与饱和度参数。
- 默认临界阻尼弹簧、动量弹簧和按压反馈参数。

`src/styles/global.css` 提供 `.liquid-glass--thin`、`.liquid-glass--regular`、`.liquid-glass--thick`、`.liquid-glass--dark` 四类基础材质，并将现有页面类映射到这些材质。复盘专属布局继续由 `src/styles/review.css` 负责，但引用同一套令牌。

### 运动基础设施

- 引入成熟的 `motion` 运动库处理可中断弹簧和释放速度传递，不手写通用弹簧求解器。
- 在 `src/motion/` 增加项目级手势辅助层，统一处理指针捕获、约 10px 迟滞、最近位置历史、释放速度、动量投射、边界橡皮筋和减少动态效果。
- 只对已有明确手势语义的对象使用拖拽：复盘轮播、背诵摇杆、支持手势关闭的抽屉。普通信息卡只有按压与悬停反馈，不可随意移动。
- 玻璃高光由 AppShell 级指针事件委托更新当前交互表面的 CSS 坐标，每帧最多更新一次，离开表面后立即停止。

### 组件责任

- `AppShell`：应用背景、深色玻璃侧栏、浮动页面容器和统一指针高光入口。
- 总览：资讯、日历、倒计时、备忘和统计区全部使用标准玻璃；按钮和日期格使用薄玻璃。
- 录入：编辑器、属性区和图片拖入区使用标准玻璃；工具条、输入框和模板选择使用薄玻璃。
- 背诵：封面、题卡和抽题台使用不同厚度玻璃；摇杆保持三维实体感并使用速度感知回弹。
- 卡片库：卡片、筛选和批量工具全面玻璃化；详情抽屉使用厚玻璃。
- 复盘：板块、工具条、相纸和管理区统一玻璃层级；相纸保持图片可检查性，不对图片本身加模糊。
- 设置：主题选择、体验设置和音乐入口使用标准玻璃，选项使用薄玻璃；减少动态效果继续即时预览。

## 交互设计

### 按钮

- `pointerdown` 或 CSS `:active` 在 100ms 内显示约 0.97 到 0.98 的缩放和内高光变化。
- 业务动作仍在释放或点击时提交；移出命中范围可以取消，不在按下时执行不可逆操作。
- 加载按钮使用稳定宽高、进度图标和同步锁，不因文案变化跳动布局。

### 复盘轮播

- 指针移动与卡片位置一比一跟随，并保留抓取点偏移。
- 记录最近若干次位置与时间，释放时计算 px/s 速度。
- 使用指数衰减投射终点，再选择上一张、当前张或下一张；速度方向优先于单纯位置。
- 释放速度交给动量弹簧，手势带动量时使用约 0.8 阻尼比，普通回正使用临界阻尼。
- 边缘使用渐进阻力，不出现突然硬停；弹簧运行期间可再次抓取并从当前屏幕位置继续。

### 抽屉与弹窗

- 卡片详情抽屉沿右侧同一路径进出，桌面支持遮罩和关闭按钮，触控设备支持从抽屉把手横向拖动关闭。
- 抽屉释放时依据速度方向和投射终点决定关闭或回位；动画期间仍可重新抓取。
- 弹窗从触发控件方向材质化，透明度、模糊和缩放同步变化；关闭沿原路径返回。
- 焦点进入、Tab 循环、Esc 关闭和关闭后返回触发控件继续作为强制行为。

### 背诵摇杆

- 继续只支持向下拉动，保留 8px 到 10px 迟滞、多指针保护和指针捕获。
- 杆体、球头、手部和阴影同步变化；释放速度传给回弹弹簧。
- 超过抽题阈值才提交动作，取消和捕获丢失只回位，不触发抽题。

## 辅助功能

### 减少动态效果

- 系统 `prefers-reduced-motion` 优先，其次当前即时预览，最后读取已保存设置。
- 停用位移、弹簧、惯性、翻页和滚动轮播；状态变化改为不超过 200ms 的透明度交叉淡化或立即切换。
- 业务完成不能依赖动画或定时器，减少动态时直接进入最终状态。

### 减少透明度

- `prefers-reduced-transparency` 下把玻璃背景提升到接近实色并关闭 `backdrop-filter`。
- 保留边框、阴影和层级差异，不能因为失去模糊而混成同一平面。

### 高对比度与回退

- `prefers-contrast: more` 下使用接近实色的背景和更明确边框。
- 不支持 `backdrop-filter` 的浏览器自动使用预设实色回退。
- 所有文字和主要控件保持可读对比度，图片查看器不对被检查图片施加透明度或滤镜。

## 状态与数据流

- 本轮不新增服务器状态。玻璃效果只依赖 CSS、媒体查询和现有浏览器本地设置。
- 当前动效设置继续使用 `gongkao-experience-v1`；不改变其版本和数据结构。
- 拖拽位置、速度和弹簧对象只存在组件内存中，组件卸载时取消动画和事件监听。
- 抽屉、弹窗和异步按钮继续沿用现有业务状态与请求锁，不让视觉动画控制业务成功或失败。

## 错误与中断处理

- 指针取消、捕获丢失、窗口失焦和组件卸载都终止当前手势并回到稳定状态。
- 新手势开始时停止旧弹簧，从实时呈现位置和当前速度继续，不从旧目标值跳转。
- API 失败只恢复按钮可用状态并显示现有错误提示，不回滚无关视觉设置。
- `motion` 加载或运行异常不能阻塞业务操作；减少动态路径和无动画最终状态始终可用。

## 测试策略

### 自动化测试

- 先补失败测试，再实现运动和材质变更。
- 单元测试覆盖动量投射、速度方向、边界阻力、减少动态分支和动画取消。
- 组件测试覆盖按钮同步锁、抽屉焦点、Esc、遮罩、拖动关闭、反向打断、复盘卡片速度切换和摇杆取消。
- 保留现有 397 项测试并执行全量回归、类型检查、生产构建和差异检查。

### 浏览器验收

- 使用 Playwright CLI 验收 1440×1000、390×844，并增加中等宽度检查。
- 检查六个页面的横向溢出、文字重叠、玻璃层级、背景图片加载和控制台错误。
- 用真实指针轨迹验证复盘卡片一比一跟手、速度切换、弹簧中途重抓和抽屉拖动关闭。
- 分别模拟减少动态效果、减少透明度、高对比度和不支持 `backdrop-filter`。
- 对桌面与移动端保存截图，并检查主要玻璃区域不是纯空白或纯透明。

## 性能预算

- 只给可见的大表面启用 `backdrop-filter`，嵌套小控件不重复模糊。
- 手势更新只改 `transform` 和 `opacity`，使用 `requestAnimationFrame` 合并高光坐标更新。
- `will-change` 只在手势开始到弹簧结束期间启用。
- 生产构建记录新增依赖后的包体积变化；如果主包明显增大，运动代码按页面拆分加载。
