# 公考记忆卡基础版实施计划

> **供智能体执行者使用：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans` 技能，按任务逐项实施。所有步骤使用复选框跟踪；同一时间只执行一个任务。

**目标：** 构建一套可在 Windows 本地启动、使用 SQLite 持久化、通过 DeepSeek V4 Flash 自动规范内容，并支持混合抽卡和 FSRS 复习的公考记忆卡基础版。

**架构：** 前端使用 React、TypeScript 和 Vite；本机 Node.js、Express 服务统一负责 SQLite、图片、DeepSeek、FSRS 和备份恢复。卡片先在事务 A 中保存原文，事务外调用 DeepSeek，再在事务 B 中原子写入规范字段和题面。

**技术栈：** React、TypeScript、Vite、Express、Zod、better-sqlite3、ts-fsrs、TipTap、Vitest、Testing Library、Supertest、Playwright。

---

## 一、执行约束

1. 每个任务按“失败测试 → 验证失败 → 最小实现 → 验证通过 → 文档与日志 → 提交”执行。
2. 每个任务只修改本任务列出的文件；需要跨任务文件时先停止并说明依赖。
3. `progress.md` 只在末尾追加，不改写既有内容。
4. 每次实际行为、配置或依赖变化都同步更新 `docs/本地运行与数据管理.md`。
5. 不使用用户在聊天中暴露的旧密钥；真实密钥只由用户写入本机 `.env`。
6. `.env`、`data/`、`.tmp/`、测试截图以外的运行产物不得提交。
7. 每个提交前运行 `git diff --check` 和该任务列出的验证命令。

- [ ] **步骤 4：实现最小前后端入口**

```ts
// server/app.ts
import { existsSync } from 'node:fs';
import path from 'node:path';
import express from 'express';

export function createApp() {
  const app = express();
  app.use(express.json({ limit: '2mb' }));
  app.get('/api/health', (_request, response) => response.json({ status: 'ok' }));
  const clientDirectory = path.resolve(process.cwd(), 'dist/client');
  if (existsSync(clientDirectory)) {
    app.use(express.static(clientDirectory));
    app.use((request, response, next) => {
      if (request.method !== 'GET' || request.path.startsWith('/api/') || request.path.startsWith('/uploads/')) return next();
      response.sendFile(path.join(clientDirectory, 'index.html'));
    });
  }
  return app;
}
```

import path from 'node:path';

const environmentSchema = z.object({
  PORT: z.coerce.number().int().positive().default(8787),
  DATA_DIR: z.string().default('./data'),
  DEEPSEEK_BASE_URL: z.string().url().default('https://api.deepseek.com'),
  DEEPSEEK_MODEL: z.literal('deepseek-v4-flash').default('deepseek-v4-flash'),
  DEEPSEEK_API_KEY: z.string().default(''),

export function readConfig(environment: NodeJS.ProcessEnv) {

  return {
    port: value.PORT,
    dataDir: path.resolve(value.DATA_DIR),
    deepseek: {
      baseUrl: value.DEEPSEEK_BASE_URL,
      model: value.DEEPSEEK_MODEL,
      apiKey: value.DEEPSEEK_API_KEY,
    },
  };
}

- [ ] **步骤 3：实现数据库管理器和迁移器**

`database.ts` 导出 `createDatabaseManager(filePath)`，内部启用 `journal_mode = WAL`、`foreign_keys = ON`，公开 `get()`、`close()`、`replaceFrom(filePath)`。`replaceFrom` 必须先关闭连接、替换文件、重新打开并执行迁移。不得导出裸全局连接。

`tests/helpers/testDatabase.ts` 使用独立临时目录：

```ts
import { mkdtempSync, rmSync } from 'node:fs';
import { tmpdir } from 'node:os';
import path from 'node:path';
import { createDatabaseManager } from '../../server/db/database';
import { migrate } from '../../server/db/migrations';

export function createTestDatabase() {
  const directory = mkdtempSync(path.join(tmpdir(), 'gongkao-test-'));
  const manager = createDatabaseManager(path.join(directory, 'gongkao.db'));
  migrate(manager.get());
  return {
    db: manager.get(),
    manager,
    directory,
    dispose() {
      manager.close();
      rmSync(directory, { recursive: true, force: true });
    },
  };
}
```

  notes: z.string().max(20_000),
  tags: z.array(z.string().trim().min(1).max(40)).max(12),
  quiz_items: z.array(quizItemSchema).max(2),
}).superRefine((value, context) => {
  if (value.question_type === 'single' && (value.quiz_items.length !== 1 || value.quiz_items[0]?.direction !== 'single')) {

const cardId = repository.insertRawCardInTransaction(input); // 事务 A 提交

// server/study/scheduler.ts
import { Rating, State, createEmptyCard, fsrs, type Card } from 'ts-fsrs';
import type { QuizItemSchedulingState } from '../../shared/contracts';

export const masteryRank = { unseen: 0, again: 1, hard: 2, good: 3 } as const;

export function toFsrsRating(value: 'again' | 'hard' | 'good') {
  return { again: Rating.Again, hard: Rating.Hard, good: Rating.Good }[value];
}

export function toFsrsCard(item: QuizItemSchedulingState): Card {
  return {
    due: new Date(item.dueAt),
    stability: item.stability,
    difficulty: item.difficulty,
    elapsed_days: item.elapsedDays,
    scheduled_days: item.scheduledDays,
    learning_steps: item.learningSteps,
    reps: item.reps,
    lapses: item.lapses,
    state: item.state as State,
    last_review: item.lastReviewAt ? new Date(item.lastReviewAt) : undefined,
  };
}

export function scheduleNext(item: QuizItemSchedulingState, rating: 'again' | 'hard' | 'good', now: Date) {
  const scheduler = fsrs();
  const current = item.reps === 0 ? createEmptyCard(now) : toFsrsCard(item);
  return scheduler.next(current, now, toFsrsRating(rating));
}

  const response = await fetch(path, { ...init, headers: { 'Content-Type': 'application/json', ...init?.headers } });
  if (!response.ok) {
    const body = await response.json().catch(() => ({ code: 'unknown', message: '请求失败' }));

  }

}

  }
  return response.json() as Promise<T>;
}
