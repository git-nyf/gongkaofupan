# AI 公考教练实施计划

> **供智能体执行：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans`，按任务逐项实施。步骤使用复选框跟踪。

**目标：** 在现有公考记忆卡应用中新增独立 AI 公考教练，按“花生十三负责判断推理、资料分析、数量关系，张弓负责言语理解”的规则提供题目解析、连续追问、卡片上下文、训练计划和可追溯联网来源。

**架构：** 浏览器只访问本项目服务端。服务端教练服务负责题型路由，并分别调用花生 MCP、用户本机张弓 Skill、Tavily Search 和独立 DeepSeek 教练提供者；每个外部能力通过小型适配器隔离并可单独降级。首期会话仅保存在页面状态，不修改数据库。

**技术栈：** React 18、React Router、Express、TypeScript、Zod、DeepSeek Chat Completions、官方 Model Context Protocol TypeScript SDK、Tavily Search、Vitest、Testing Library、Playwright。

---

## 文件职责

- `shared/contracts.ts`：前后端共享的教练模式、状态、请求、答复和来源契约。
- `server/coach/huasheng.ts`：花生 MCP 连接、工具调用、题型路由和方法上下文归一化。
- `server/coach/zhangGong.ts`：从本机目录按需读取张弓 Skill，并输出受限方法上下文。
- `server/coach/webSearch.ts`：Tavily 联网搜索和来源字段清洗。
- `server/coach/deepseek.ts`：教练专用 DeepSeek 请求、系统提示词和结构化响应校验。
- `server/coach/service.ts`：老师路由、卡片上下文、外部适配器编排和错误分类。
- `server/coach/routes.ts`：状态与消息接口的请求校验和安全响应映射。
- `src/pages/CoachPage.tsx`：教练对话、模块切换、卡片搜索、状态和右侧辅助区。
- `src/styles/coach.css`：教练页响应式 Apple 风格玻璃界面。
- `docs/AI公考教练.md`：安装、配置、老师分工、降级和使用说明。

- [ ] **步骤 3：实现花生 MCP 适配器**

- 言语只返回路由结果，不调用花生言语脚手架。
