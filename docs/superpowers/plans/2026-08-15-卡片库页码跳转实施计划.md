# 卡片库页码跳转实施计划

> **供智能体执行：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans` 技能逐项实施，步骤使用复选框跟踪。

**目标：** 在卡片库现有分页玻璃控件内增加可输入页码，并支持 Enter、失焦、Escape、边界限制和加载禁用。

**架构：** 页码草稿保留在 `CardsPage` 的本地状态中，提交后复用现有 `setFilter({ page })` 和 URL 查询参数数据流，不新增后端契约。分页输入样式继续归属 `cards-glass.css`，行为与视觉回归统一放入现有卡片库前端测试。

**技术栈：** React 18、React Router、TypeScript、Vitest、Testing Library、CSS。

- [ ] **步骤 3：实现最小交互**

在 `CardsPage` 中增加页码草稿与取消标记：

```tsx
const [pageDraft, setPageDraft] = useState(() => String(filters.page));
const cancelPageCommit = useRef(false);

useEffect(() => {
  setPageDraft(String(filters.page));
}, [filters.page]);

const commitPageDraft = () => {
  if (!/^\d+$/.test(pageDraft)) {
    setPageDraft(String(filters.page));
    return;
  }
  const nextPage = Math.min(totalPages, Math.max(1, Number(pageDraft)));
  setPageDraft(String(nextPage));
  if (nextPage !== filters.page) setFilter({ page: nextPage });
};
```

将静态页码文字替换为：

```tsx
<span className="cards-pagination__status">
  <span>第</span>
  <input
    aria-label="页码"
    className="cards-pagination__input"
    disabled={loadState === 'loading'}
    inputMode="numeric"
    onBlur={() => {
      if (cancelPageCommit.current) {
        cancelPageCommit.current = false;
        setPageDraft(String(filters.page));
        return;
      }
      commitPageDraft();
    }}
    onChange={(event) => {
      if (/^\d*$/.test(event.target.value)) setPageDraft(event.target.value);
    }}
    onKeyDown={(event) => {
      if (event.key === 'Enter') {
        event.preventDefault();
        commitPageDraft();
      }
      if (event.key === 'Escape') {
        event.preventDefault();
        cancelPageCommit.current = true;
        setPageDraft(String(filters.page));
        event.currentTarget.blur();
      }
    }}
    pattern="[0-9]*"
    style={{ width: `${Math.max(2, String(totalPages).length + 1)}ch` }}
    type="text"
    value={pageDraft}
  />
  <span aria-hidden="true">/</span>
  <span>{totalPages} 页</span>
</span>
```
