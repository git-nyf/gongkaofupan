# 不会标注与加权抽取实施计划

> **供智能体执行：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans`，按任务逐个完成实现、验证、日志追加和提交。

**目标：** 去掉所有用户可见的星级与熟练度，让卡片级“不会标注次数”驱动背诵记录、薄弱复盘和随机加权抽取，并完成可直接使用的基础版。

**架构：** SQLite 旧字段、FSRS 状态和历史日志继续保留，不执行数据库迁移。外部只暴露 `unknown | known` 两种复习结果；服务端映射为内部 `again | good`，复用 `cards.wrong_count` 记录不会次数。随机模式在到期池和补齐池内分别执行静态权重、无放回抽取，固定模式保持稳定顺序。

**技术栈：** React、React Router、TypeScript、Express、Zod、SQLite、`ts-fsrs`、Vitest、Testing Library、Playwright。

---

## 文件职责

- `shared/contracts.ts`：定义不含星级与掌握度的外部卡片、会话和复习契约。
- `server/cards/*`：使用数据库内部默认值保存旧字段，对外拒绝和隐藏废弃字段。
- `server/study/*`：执行两种复习结果、FSRS 映射和加权不放回抽取。
- `server/analytics/*`：按不会标注生成总览与复盘数据。
- `src/pages/EntryPage.tsx`：保留录入核心字段，不显示或提交星级、熟练度。
- `src/pages/CardsPage.tsx`：六列表格展示不会标注，移除旧筛选和批量加星。
- `src/pages/StudyPage.tsx`：完成卡组设置、翻面、不会标注、手动下一张和轮次总结。
- `src/pages/DashboardPage.tsx`、`ReviewPage.tsx`、`SettingsPage.tsx`：完成总览、复盘和本地设置。
- `e2e/*` 与 `scripts/*`：验证真实主闭环、视觉、安全、重启和构建运行。
- `progress.md`：每个任务只在文件末尾追加实现、验证、文件清单与回滚方式。

- [ ] **步骤 4：实现内部映射和事务**

```ts
export interface ReviewInput {
  quizItemId: string;
  result: 'unknown' | 'known';
}

export type InternalReviewRating = 'again' | 'good';

const internalRating = input.result === 'unknown' ? 'again' : 'good';
const scheduled = scheduleNext(state, internalRating, reviewedAt);
```

调度器改为接收 `InternalReviewRating`，不再从外部 `ReviewInput` 推导内部类型。继续在同一 SQLite 事务中更新题面、写日志、按 `unknown` 增加 `wrong_count` 和更新时间。响应只返回 `result`、`nextDueAt`、`wrongCount`。

- [ ] **步骤 5：实现静态权重无放回抽取**

建池时统计同卡题面数并固定权重：

```ts
const weight = (1 + item.wrong_count) / itemCountByCard.get(item.card_id)!;
```

每次以 `random() * totalWeight` 命中区间，移除选中项及其固定权重；不要在移除后重算同卡剩余项。到期池和未到期池分别建池。`order === 'fixed'` 不调用权重函数。

- [ ] **步骤 6：调整统计语义**

总览待攻克按 `cards.wrong_count > 0`；薄弱板块只统计内部 `again`；高频不会标注以卡片 `wrong_count` 降序，同数按最近 `again` 日志时间排序。历史 `hard` 不参与新指标。
