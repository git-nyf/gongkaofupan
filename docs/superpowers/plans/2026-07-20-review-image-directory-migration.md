# 复盘图片分类目录迁移实施计划

> **供智能体执行：** 必须按测试驱动方式逐项实施，并在每项完成后运行对应验证。

**目标：** 将复盘错题图片自动迁移并持续保存到按大板块、小板块划分的可读目录中，同时保留 `manifest.json` 内稳定编号，并按板块与加入时间生成文件名。

**架构：** 清单升级为 v3，`storedName` 保存相对路径；路径由板块名、小板块名、各自稳定编号前缀、图片加入时间和图片稳定编号确定。读取 v1/v2 时执行可重复、可续跑的文件移动，全部图片就位后再原子替换清单；新增板块和小板块时立即创建对应目录。

**技术栈：** Node.js 文件系统 API、TypeScript、Vitest、Express 现有复盘图片服务。
