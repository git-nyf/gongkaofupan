# 背诵加权抽取

## 适用范围

背诵会话选择“随机”顺序时，系统按照卡片权重进行无放回抽取；选择“固定”顺序时，仍按原有创建时间和题面顺序排列。归档、AI 状态、板块、标签、日期和指定卡片等筛选规则保持不变。

## 权重规则

```text
基础权重 = (1 + 不会次数) / (1 + 熟练次数)

从未抽取：时间系数 = 2.0
已经抽取：时间系数 = clamp(0.5 + 距上次抽取天数 / 14, 0.5, 2.0)

卡片权重 = max(0.25, 基础权重 × 时间系数)
题面权重 = 卡片权重 / 该卡片参与本次抽取的题面数
```

- 不会次数来自卡片累计的 `wrong_count`。
- 熟练次数来自该卡片评分为 `good` 的历史复习记录总数。
- 新卡的不会次数和熟练次数均为 0，且没有上次抽取时间，因此卡片权重为 `2.0`。
- 刚抽取过的卡片时间系数为 `0.5`，之后线性恢复，第 21 天达到 `2.0` 上限。
- 卡片权重最低为 `0.25`，已掌握卡片仍会保留被抽到的机会。
- 一张卡片有多个题面时，各题面均分卡片总权重，避免题面数量放大整张卡片的抽取概率。

## 数据记录

数据库第 10 版迁移为卡片增加可空的 `last_drawn_at` 字段和查询索引。历史卡片的字段保持为空，按从未抽取处理，不修改已有卡片内容和复习记录。

背诵会话成功组装题面后，系统用同一时间更新本次抽中卡片的 `last_drawn_at`；同一张卡片在一轮会话中只更新一次，未抽中的卡片不更新。
