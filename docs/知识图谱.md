# 知识图谱使用说明

## 功能定位

- 通过左侧导航进入“图谱”，页面地址为 `/graphs`。
- 横向编辑是唯一的数据编辑入口；2D 圈层图和 3D 星系图读取同一份节点、卡片与关系数据，只提供预览。
- 图谱数据独立于卡片库、背诵和复盘流程，不会修改原始卡片内容。

## 横向编辑

### 录入节点

- 在“中心主题”输入框录入内容并按回车，可以创建根节点。
- 点击节点右侧加号并录入内容，会创建子节点和本次明确指定的父子分支。
- 系统按父子关系从左向右自动排布，不需要手工选择节点层级，也不支持自由拖动节点位置。
- 点击节点后，底部弹出节点详情；自定义节点可以修改标题和正文，也可以删除节点或错误连线。
- 底部详情使用近乎不透明的浅色磨砂背景，避免画布节点和连线干扰阅读。

### 搜索添加卡片

- 在目标父节点右侧点击加号后，可在子节点弹窗中选择手动录入或“搜索卡片”。
- 搜索只请求去重后的首屏用户初始稿；结果列表可独立滚动，不会带动画布。
- 搜索区域按浏览器视口限制最大高度，顶部表单占用空间时仍可完整滚动查看结果。
- 点击搜索结果后，卡片会按父节点的下一层级加入，并自动建立“父节点 → 卡片节点”的分支关系。
- 同一张卡片重复添加时会定位已有节点，不会产生重复节点。

### 查看完整内容

- 横向节点只显示便于浏览的短摘要。
- 鼠标悬浮在横向节点上，会显示与卡片库预览一致的完整用户初始稿；预览会自动限制在窗口内部。
- 自定义节点悬浮时显示完整标题和正文。
- 点击节点后的底部详情用于持续查看和编辑，悬浮预览用于快速浏览。

### 缩放与平移

- 在横向画布内按住 `Ctrl` 滚动鼠标滚轮，只缩放思维导图，不改变浏览器页面比例。
- 在画布空白处按住鼠标并拖动，可以平移查看超出当前区域的分支。
- 节点和输入控件不会触发空白画布平移，避免误操作。
- 手机和平板使用纵向页面布局，工具栏可横向滑动，画布保持独立缩放和滚动。

### 撤销与导出

- 横向编辑支持工具栏撤销按钮和 `Ctrl+Z`，可撤销本轮节点、关系和内容操作。
- “导出 Markdown”会输出当前图谱的节点正文和父子关系，便于离线保存。

## 2D 圈层预览

- 2D 模式自动读取横向编辑结果，并按径向圈层生成只读预览。
- 根节点位于中心，后续节点按父分支扇区向外排布，尽量减少错位和连线交叉。
- 所有关系线始终可见；选中节点时，该节点到根节点的祖先路径会加粗发光。
- 鼠标悬浮节点时显示完整卡片或自定义节点内容，点击节点时使用底部详情查看。
- 按住 `Ctrl` 滚动鼠标滚轮只缩放 2D 画布，不改变浏览器比例。

## 3D 星系预览

### 太阳系布局

- 根节点位于中心并作为太阳。
- 第二层节点统一分布在内层轨道，更深层节点按层级进入半径更大的同心轨道。
- 子节点继承父节点的放射方向，并在父分支附近展开，减少跨分支连线。
- AI 优化稿不占用主轨道，而是作为靠近所属知识星球的小陨石；解析内容不生成球体。
- 星球和连线统一使用项目红色系，通过球体大小、颜色深浅和轨道半径表达层级。

### 视角与文字

- 支持鼠标拖拽进行 360 度视角旋转，滚轮缩放镜头。
- 支持放大、缩小、适配视图和自动旋转开关；用户操作后不会突然重置视角。
- 节点文字使用始终朝向相机的公告牌渲染；镜头拉近时逐级放大、拉远时适度缩小，并通过尺寸上下限避免过小或遮满画布。
- AI 小陨石的摘要在镜头拉近后显示，远景默认隐藏，避免大量文字互相遮挡；悬浮或选中时仍可查看。
- “文字摘要”和“AI 衍生球体”可以分别关闭或开启。
- 窄屏会使用更短摘要和更小标签，桌面端保持完整的可读尺寸。

## 数据规则

- `knowledge_maps` 保存专题图谱名称与时间信息。
- `knowledge_map_nodes` 保存自定义节点或卡片关联、标题、正文、层级与位置数据。
- `knowledge_map_edges` 只保存用户明确创建的父子关系。
- 横向编辑中的父子关系决定 2D 圈层与 3D 轨道层级，不需要额外维护另一套预览数据。
- 删除图谱节点会清理与该节点直接关联的连线，不会删除原始卡片。
- 3D 中的 AI 小陨石由卡片 AI 优化稿临时生成，不写入节点表。

## 操作验收

- 在横向编辑中输入根节点，再用节点加号连续添加两级子节点，确认从左向右形成清晰分支。
- 从目标父节点的加号打开搜索，滚动结果列表并添加一张卡片，确认卡片位于父节点下一层且自动建立分支。
- 在横向画布内按住 `Ctrl` 滚动，确认图谱缩放且浏览器比例不变；拖动空白处，确认画布平移。
- 悬浮横向节点和 2D 节点，确认完整内容可读且预览不超出窗口。
- 点击节点，确认底部详情背景接近不透明，背景图谱不干扰正文。
- 切换 2D 预览，确认全部关系可见，选中节点后的祖先路径高亮。
- 切换 3D 预览，确认中心太阳、同心轨道、父分支方向和 AI 小陨石均正确显示。
- 缩放 3D 镜头，确认正式节点摘要保持可读，AI 摘要在拉近后出现，手机端没有水平页面溢出。

## 工程验证

- 类型检查：`npm run typecheck`。
- 单元与集成测试：`npm test`。
- 生产构建：`npm run build`。
- 浏览器验证：打开 `/graphs`，分别检查横向编辑、2D 预览、3D 预览、节点详情和桌面与移动端布局。
