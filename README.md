# 公考记忆卡

本项目是一套本机运行的公考知识录入、AI 整理、卡片背诵和错题图片复盘工具。

## 快速启动

Windows 用户可以双击根目录的 `启动项目.cmd`。也可以使用命令行：

```powershell
npm install
npm run build
npm start
```

默认访问地址为 `http://127.0.0.1:8787`。

## 目录说明

- `src/`：React 前端页面、组件、主题与交互动效。
- `server/`：本机 API、SQLite、DeepSeek、卡片、背诵和复盘图片服务。
- `shared/`：前后端共享的数据契约。
- `tests/`：前端与服务端自动测试。
- `public/diy/`：项目内置的 DIY 背景图片，会随项目发布。
- `docs/`：正式设计、运行和数据管理文档。
- `data/`：本机卡片数据库和错题图片，不进入版本库。

## 本机数据与密钥

`.env` 可能包含 DeepSeek 密钥，`data/` 包含用户卡片和图片；两者都已被 Git 忽略。公开项目时只提交 `.env.example`，不要提交真实 `.env` 或任何 `data/` 内容。

完整的安装、备份、图片目录和接口说明见 [本地运行与数据管理](docs/本地运行与数据管理.md)。
